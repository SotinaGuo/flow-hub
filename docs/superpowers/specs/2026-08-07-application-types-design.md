# 申请类型扩展设计

## 目标

按原始产品需求补齐申请类型能力：支持差旅、采购、报销、加班四种内置申请类型，并支持用户创建一种基于预设模板的自定义申请类型。所有类型继续复用现有的申请、预览、提交、列表、详情、状态流转和统计流程。

## 范围

### 内置申请类型

| 类型标识        | 类型名称 | 表单字段                                 |
| --------------- | -------- | ---------------------------------------- |
| `travel`        | 差旅申请 | 出发地、目的地、开始日期、结束日期、事由 |
| `procurement`   | 采购申请 | 采购内容、金额、采购日期、事由           |
| `reimbursement` | 报销申请 | 报销类型、金额、发生日期、事由           |
| `overtime`      | 加班申请 | 加班日期、开始时间、结束时间、事由       |

顶层申请类型不再包含 `leave`。旧的请假 Mock 数据会替换为符合新范围的申请数据。

### 自定义申请类型

自定义申请类型在当前 Mock 会话内创建，不实现服务端持久化和完整字段设计器。用户需要填写自定义类型名称，并选择一个预设模板：

| 模板标识  | 模板名称 | 表单字段                       |
| --------- | -------- | ------------------------------ |
| `general` | 通用类   | 发生日期、事由                 |
| `amount`  | 金额类   | 金额、发生日期、事由           |
| `time`    | 时间类   | 日期、开始时间、结束时间、事由 |

自定义类型使用 `custom` 作为顶层类型标识，具体名称保存在自定义表单数据中。已提交的自定义申请需要在列表、详情、筛选和报表中正确显示。

## 数据模型

### 类型定义

```ts
type BuiltInApplicationType = 'travel' | 'procurement' | 'reimbursement' | 'overtime';
type ApplicationType = BuiltInApplicationType | 'custom';
type CustomApplicationTemplate = 'general' | 'amount' | 'time';
```

申请类型配置集中维护内置类型标签、说明和选项。自定义模板配置集中维护模板标签和字段规则，组件不自行写入类型判断以外的 Mock 配置。

### 表单数据

继续使用判别联合：

- 差旅表单使用目的地、出发地和日期范围字段。
- 采购表单使用采购内容、金额和采购日期字段。
- 报销表单保留报销类型、金额和发生日期字段。
- 加班表单保留日期和时间范围字段。
- 自定义表单通过 `customTemplate` 区分三种模板，并包含 `customTypeName`。

所有表单数据都包含申请人、部门和事由等共享字段，避免在组件中使用无约束字段访问。

## 数据流

1. 申请类型选择器从类型配置注册表读取四种内置类型和自定义入口。
2. 选择内置类型时，表单按对应的固定类型字段渲染。
3. 选择自定义类型时，先填写类型名称，再选择预设模板，表单按模板渲染。
4. 表单校验器根据类型或模板执行必填、金额、日期和时间范围校验。
5. 表单转换器将草稿转换为判别联合数据，预览和 Repository 只接收已转换的数据。
6. 展示层通过统一的类型标签和详情行格式化函数支持内置与自定义申请。
7. 统计层的 `byType` 包含五类数据，类型报表从注册表生成，避免固定三项数据。

## 兼容与边界

- 不保留 `leave` 作为兼容类型，避免产品列表继续展示已废弃的申请类型。
- 不实现自定义字段名称、字段类型、选项和字段排序配置。
- 自定义类型只在当前客户端 Mock 会话可用；页面刷新后的持久化行为不在本次范围内。
- Repository 继续保持异步接口，页面不直接依赖 Mock 数组。
- 不引入新的前端框架或表单库。

## 测试与验收

### 业务逻辑

- 类型配置包含四种内置类型和三个自定义模板。
- 四种内置类型和三个自定义模板都能创建正确的初始草稿并转换为对应联合类型。
- 校验器覆盖共享字段、日期顺序、时间顺序、金额大于零和自定义名称必填。
- 详情和列表摘要能正确展示每种类型的字段。
- 统计聚合能正确统计五种申请类型。

### 组件与页面

- 类型选择器展示四种内置类型和自定义入口。
- 自定义类型名称和模板选择控件可操作。
- 自定义模板切换时表单字段正确变化，错误提示可见。
- 列表类型筛选、详情标题和报表类型图表包含自定义类型。
